# Dr. Junaid Alam Dawar Clinic Website

A responsive clinic information website for Dr. Junaid Alam Dawar, Consultant Neurosurgeon in Bannu, Pakistan. It helps visitors learn about the clinic, view its services and photos, check typical hours, find contact details, and send an appointment request through WhatsApp.

## Live Website

https://muhammadnadeemdawar.github.io/drjunaidalamdawar/

## Technologies

- HTML5 for the page structure and content
- CSS3 for responsive layout and styling
- JavaScript for the appointment-message interaction and current year
- Local image assets (JPG, PNG, and SVG)

No package installation or build step is required.

## View Locally

1. Download or clone this repository.
2. Keep `index.html` and its image assets in their existing relative locations.
3. Open `index.html` in a web browser.

## Publish with GitHub Pages

The live site is served from this repository's `main` branch using GitHub Pages. After committing and pushing changes to `main`, GitHub Pages will publish the updated files. Allow a few minutes for the deployment to finish, then refresh the live website.
